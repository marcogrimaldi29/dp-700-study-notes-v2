DP-700 validates your ability to ingest and transform data, secure and manage an analytics solution, and monitor and optimize it — all inside Microsoft Fabric. It is a hands-on, decision-heavy exam: most questions ask which engine, which item, which order rather than "what does this do?".

How to use these notes

Start with Fabric Foundations to build the mental model (OneLake, Delta, capacities, item types), then work through the three domains in order and drill the Exam Tips & Caveats page before test day. These notes are a companion — pair every section with hands-on practice in a Fabric trial capacity and the official Microsoft Learn modules.

Exam reality check

Expect case studies, drag-and-drop ordering, "build list" sequencing, hotspot (dropdown) and yes/no statement sets. You will be asked to read short PySpark, T-SQL and KQL snippets — you rarely have to write them from scratch, but you must recognise what they do and what is wrong with them. The Exam Tips page collects the highest-yield caveats. Most questions cover GA features; commonly-used Preview features can appear.
